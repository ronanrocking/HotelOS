A desktop application for room inventory and guest management developed for an OSDL lab project.

Architecture
The codebase is segmented into five core modules for maintainability:
  - App.java: Serves as the entry point and UI coordinator.
  - Room.java: Represents the data model and the hotel's 8-field schema.
  - CsvManager.java: Manages all file I/O and data loading operations.
  - Tabs.java: Defines individual functional views and layouts.
  - UiHelper.java: Contains shared styling and input validation utilities.
